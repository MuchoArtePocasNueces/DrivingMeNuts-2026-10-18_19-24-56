# WOMEN IN GAMEX JAM 2026
Team: Dinamita
## Driving me nuts
Es un juego 2.5D de plataforma y vamos en contra del tiempo.
Debes recolectar la mayor cantidad de comida pero cada comida recolectada tiene un peso, es decir cada si tiene un peso.
Este peso, es el peso de nuestras decisiones, hay plataformas en las que si tienes mucho peso se rompen, para liberarte
del peso puedes escupir, asi mismo hay plataformas de balanza en la que necesitas demasiado peso para bajar la plataforma,
para seguir avanzando para llegar a nuestra meta.
